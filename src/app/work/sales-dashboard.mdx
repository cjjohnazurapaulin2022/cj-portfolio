## The Challenge
The sales team had no real-time visibility into key performance metrics, leading to delayed decisions and missed revenue opportunities. Reports took 4+ hours to generate manually each week.

## My Approach

### 1. Data Collection & Cleaning
- Extracted 500,000+ rows of transaction data from PostgreSQL database
- Used Python pandas to clean and validate data (handled missing values, removed duplicates)
- Standardized date formats and created calculated fields

### 2. Database Querying
- Built complex SQL queries for cohort analysis, retention metrics, and forecasting
- Created views for recurring reports to improve query performance
- Implemented query optimization techniques reducing execution time by 60%

### 3. Dashboard Development
- Designed interactive Tableau dashboard with 12+ dynamic views
- Created parameters for date ranges, product categories, and regions
- Implemented tooltips and drill-down functionality for deeper analysis

## Results & Impact
- **75% reduction** in reporting time (from 4 hours to 1 hour weekly)
- **$150K identified** in upsell opportunities through customer segmentation
- **94% forecast accuracy** achieved for quarterly revenue predictions
- **Adopted by 3 departments** (Sales, Marketing, Leadership)

## Key Features
- Real-time sales tracking by region and product category
- Customer lifetime value (CLV) analysis
- Cohort retention analysis by acquisition month
- Predictive forecasting for next quarter
